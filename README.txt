UNDANGAN WISUDA — PETUNJUK SINGKAT

1. Buka index.html di browser atau jalankan melalui Live Server.
2. Klik amplop untuk membuka undangan. Website ini tidak menggunakan musik.
4. Kisah Sitiyani ditampilkan sebagai teks, tanpa narasi suara, dengan latar
   taman, bunga, dan kupu-kupu bergerak.
5. Video kisah berada di bawah nama Sitiyani di kolom kiri. Gunakan kontrol
   video untuk memutar atau menjeda videonya.
6. Foto yang digunakan berada di folder assets:
   foto1.png (foto utama), foto2.png, foto3.png, foto4.jpg, foto5.png.
   Jika mengganti foto dengan format berbeda, sesuaikan nama file di index.html.
   Video kisah disimpan sebagai assets/vidio-kisah-sitiyani.mp4.
7. Jadwal yang ditampilkan:
   Wisuda: Minggu, 15 November 2026 pukul 07.00 WIB.
   Sesi foto pertama: pukul 11.00 WIB di Taman Unpam Viktor.
   Sesi foto kedua: pukul 16.15 WIB di Taman Viktor Unpam.
8. Website ini statis. Untuk dibagikan melalui link, unggah folder ini ke
   layanan hosting statis seperti GitHub Pages, Netlify, atau hosting pribadi.

Catatan:
- Font dan tautan Google Maps memerlukan koneksi internet.
- Hormati hak cipta foto dan video yang digunakan.
